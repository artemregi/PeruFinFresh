## Шаг 1 — Создать Google Таблицу

1. Открой [sheets.google.com](https://sheets.google.com) и создай **новую таблицу**
2. Назови её, например: `FinFresh Waitlist`
3. Скопируй **ID таблицы** из адресной строки браузера:
   ```
   https://docs.google.com/spreadsheets/d/ВОТ_ЭТОТ_ID/edit
   ```

---

## Шаг 2 — Создать Apps Script

1. В таблице нажми: **Расширения → Apps Script**
2. Удали весь код в редакторе
3. Открой файл `google-apps-script.gs` из этой папки и скопируй весь код
4. Вставь код в редактор
5. В строке `var SPREADSHEET_ID = '...'` замени значение на ID твоей таблицы
6. Нажми **Сохранить** (Ctrl+S или значок дискеты)

---

## Шаг 3 — Развернуть как Web App

1. Нажми **"Развернуть"** (Deploy) → **"Новое развёртывание"**
2. Выбери тип: **Веб-приложение (Web app)**
3. Настройки:
   - **Описание**: FinFresh Waitlist API
   - **Выполнять от имени**: Я (Me)
   - **Доступ**: Все (Anyone)
4. Нажми **"Развернуть"** и разреши доступ
5. **Скопируй URL** — он выглядит примерно так:
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```

---

## Шаг 4 — Вставить URL в сайт

Открой `index.html`, найди эту строку (примерно в конце файла):

```javascript
var WL_SCRIPT_URL = 'ВСТАВЬТЕ_СЮДА_URL_GOOGLE_APPS_SCRIPT';
```

Замени `'ВСТАВЬТЕ_СЮДА_URL_GOOGLE_APPS_SCRIPT'` на скопированный URL:

```javascript
var WL_SCRIPT_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
```

---

## Шаг 5 — Проверить

1. Открой сайт в браузере

## Частые вопросы

**Q: Почему используется `mode: 'no-cors'`?**
A: Google Apps Script не поддерживает CORS-заголовки, поэтому браузер не может прочитать ответ. Это нормально — данные всё равно сохраняются в таблицу. При успехе показывается сообщение об успехе.

**Q: Что если хочу также получать уведомления на почту?**
A: В Apps Script добавь в функцию `doPost`:
```javascript
MailApp.sendEmail('твоя@почта.com', 'Новый лид FinFresh!', 'Email: ' + data.email);
```

**Q: Лимиты Google Apps Script?**
A: Бесплатный аккаунт: 20 000 запросов в день — этого более чем достаточно для сбора лидов.

**Q: Можно ли подключить несколько кнопок?**
A: Да — вызывай `openWaitlistModal()` из любой кнопки на странице.
